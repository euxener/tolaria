## New Features

- 🌗 **Hybrid appearance** — A new Settings → Appearance option pairs a dark sidebar with light note content.
- 💬 **Discord in the app** — A Discord button in the bottom bar and a Discord box in the Contribute panel take you straight to the Tolaria community.
- 📱 **Tolaria for iOS banner** — A banner at the bottom of the window links to Tolaria for iOS.
- 🧠 **Skills in the AI panel** — Claude Code in the AI panel can now use your Skills.

## Improvements

- 🖼️ **Images dropped once** — Dropping an image from Finder inserts it once instead of twice.
- 💾 **Markdown preserved on save** — Saving no longer rewrites inline code, entities, or table alignment you didn't touch.
- ↩️ **Table cell line breaks persist** — Line breaks inside table cells survive closing and reopening the app.
- 🧷 **Code block pickers stay put** — Language pickers stay attached to their code block while you scroll.
- 🔍 **Tooltips at any zoom** — Tooltips look and work correctly at zoom levels other than 100%.
- 🧹 **No stray table handle** — The table drag handle no longer appears in notes without a table.
- 🖨️ **Cleaner PDF export** — Export to PDF prints the note's content instead of the sidebar.
- 🏷️ **Type defaults on new notes** — Notes created from a Type view get that Type's default properties.
- 🎯 **Focus after delete** — Deleting a note moves focus to the next note in the list.
- 📁 **Folder menu in mounted vaults** — Right-clicking a folder in a mounted vault now opens its context menu (thanks @dajiaohuang).
- ⌨️ **Tab during IME composition** — Tab and Shift+Tab no longer indent nested list items while a Chinese, Japanese, or Korean IME composition is open (thanks @DarkMagician55).
- 🌍 **Translation fixes** — Update banner errors and the Slovak settings shortcut are now translated.

## Stability and Fixes

- Fresh installs on Apple Silicon no longer get stuck on the loading screen without onboarding or Settings.
- Renaming an attachment with non-Latin characters no longer breaks the vault.
- Clicking an image in a note no longer runs the editor out of memory, and the app no longer freezes while opening and editing notes.
- Selecting cells in spreadsheets no longer throws an error, and whiteboards no longer show the developer debug menu that could crash the board.
- Imported PDFs preview again on Windows and Linux, and clicking the sidebar on Windows no longer crashes the UI.
- Plenty of under-the-hood cleanup, test, and release-pipeline work to keep Tolaria fast and reliable.
